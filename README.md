# Sopa Solidária

App do grupo de sopa solidária: compras com orçamento, caixa e balanço em PDF, agenda com escala de voluntários, notas, receitas e despensa.

**Abrir o app:** https://brandaorenato.github.io/sopa-solidaria/

No iPhone: abra o link no Safari → Compartilhar → Adicionar à Tela de Início.

Os dados do grupo não ficam aqui: ficam nos aparelhos e no Supabase do grupo.

Desenvolvido por Renato Brandão.
